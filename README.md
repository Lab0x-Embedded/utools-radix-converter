# 进制转换（uTools 插件）

嵌入式 / 开发场景常用的进制转换工具：HEX / DEC / BIN / OCT 实时互转，并把「位宽补码」和「字节序」这两个最容易出错的地方一起解决。

## 功能

- **四进制联动**：HEX / DEC / BIN / OCT 实时互转，点击任意行即复制（复制内容不带分组空格，可直接粘进代码）
- **自动识别前缀**：`0x` / `0b` / `0o` 自动判定进制，也可手动指定按 N 进制解析
- **按位宽解释**：8 / 16 / 32 / 64 位下的无符号值与有符号值（补码），如 `0xFFFFFFFF` → `4294967295` / `-1`
- **字节序**：大端 / 小端字节序列，如 `0x12345678` → `12 34 56 78` / `78 56 34 12`
- **容错**：支持空格、下划线、逗号分隔与全角字符（`０ｘ１Ｆ`）；支持负数；任意位数用 `BigInt` 计算，不丢精度
- 深浅色跟随系统，窗口高度自适应

## 如何使用

需要先安装 [uTools](https://www.u-tools.cn)。在发布到应用市场之前，可用 uTools 开发者工具的「接入开发」指向本项目目录，或把 `dist/` + `public/plugin.json` + `public/logo.png` 打成离线安装包使用。

### 三种打开方式

| 方式 | 操作 |
|---|---|
| 打开转换界面 | 在 uTools 搜索框输入 `进制转换`（也支持 `进制` / `radix` / `base`） |
| 看代码里的常量 | 选中 `0x7FFFFFFF` → 按 uTools 热键（选中内容自动带入搜索框）→ 选「十六进制转换」 |
| 输入字面量 | 直接在主搜索框输入 `0b1010`、`0o777`，选对应指令进入 |

从匹配指令进入时输入框会自动预填，点 DEC 行的「粘贴」，十进制结果就直接替换回原来的编辑器窗口。

### 快捷键

| 按键 | 作用 |
|---|---|
| `↑` / `↓` | 切换高亮行 |
| `Enter` | 复制高亮行 |
| `⌘/Ctrl + Enter` | 把高亮行的值粘贴回上一个活动窗口 |
| 点击任意行 | 复制该行 |
