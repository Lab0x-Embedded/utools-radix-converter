## 四、插件应用介绍（含用户手册）

下面整段可直接粘贴到「插件应用介绍」输入框。

---

一个为写代码、调硬件准备的小工具：把十六进制、十进制、二进制、八进制放在一起实时互转，并顺手解决两个最容易出错的地方——**按位宽看补码**和**大端小端字节序**；再给一个**容量换算**，把 `0x100000` 直接读成 `1 MiB`。

### 适用场景

- 看代码或日志里的 `0x7FFFFFFF`，想知道十进制是多少
- 配置寄存器时，`0x0F00` 到底置了哪几位
- 通信调试时，`0x12345678` 在设备里是 `12 34 56 78` 还是 `78 56 34 12`
- `0xFFFFFFFF` 当 32 位有符号数是 `-1` 还是 `4294967295`
- 把二进制字面量反推成十六进制
- 看到 `0x100000` 想知道这是多大的 flash / 分区，要换算成 KiB / MiB

### 功能

- **四进制联动**：HEX / DEC / BIN / OCT 实时互转，输入任意一种，其余三种同步更新
- **点击即复制**：点任意一行就能复制，且复制内容不带分组空格，可直接粘进代码
- **前缀自动识别**：`0x` / `0b` / `0o` 自动判定进制；也可以手动指定「按 N 进制解析」
- **按位宽解释**：8 / 16 / 32 / 64 位下分别给出无符号值与有符号值（补码），并显示补码的 HEX / BIN
- **字节序**：同时给出大端与小端字节序列
- **容量换算**：把当前数值换算成容量单位（二进制 1024 进制：B / KiB / MiB / GiB / TiB），输入 `0x100000` 即显示 `1 MiB`；容量表示与原始字节数都能一键复制
- **任意位宽不丢精度**：数值用 `BigInt` 计算，64 位寄存器值、超长十六进制都不会掉精度
- **容错输入**：允许空格、下划线、逗号分隔（`0x12 34_56`）；中文输入法下的全角字符（`０ｘ１Ｆ`）也能识别；支持负数
- **深浅色跟随系统**，窗口高度自适应，不占屏幕

### 使用方法

**三种打开方式**

1. **打开转换界面**：在 uTools 搜索框输入 `进制转换`（也支持 `进制` / `radix` / `base`）
2. **看代码里的常量**：在编辑器里选中 `0x7FFFFFFF` → 按 uTools 热键（选中内容会自动带入搜索框）→ 选择「十六进制转换」
3. **输入字面量**：直接在 uTools 搜索框输入 `0b1010`、`0o777`，选择对应的转换指令

从匹配指令进入时输入框已经自动填好，点 `DEC` 行的「粘贴」，十进制结果会**直接替换回原来的编辑器窗口**，不用手动复制粘贴。

**界面说明**

- 顶部输入框：输入任意形式的数值；右侧下拉可强制指定进制（默认自动识别）
- 四行结果：`HEX` / `DEC` / `BIN` / `OCT`，每行都可「复制」或「粘贴」（粘贴 = 隐藏 uTools 并把该值输入到上一个活动窗口）
- 高亮：打开后默认高亮「输入所属的进制行」（该行左侧有竖条标识），`↑` / `↓` 可移动高亮，回车、`⌘/Ctrl + Enter` 都作用于高亮行
- 结果下方「容量换算」：显示当前数值的容量表示（1024 进制）与原始字节数，只对非负数值显示
- 「按位宽解释」：切换 8 / 16 / 32 / 64 位，查看无符号值、有符号值、补码 HEX / BIN、大端 / 小端字节

**快捷键**

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` | 切换高亮行 |
| `Enter` | 复制高亮行 |
| `⌘/Ctrl + Enter` | 把高亮行的值粘贴回上一个活动窗口 |
| 鼠标点击任意行 | 复制该行 |

### 数值能力与限制

- 支持 2 / 8 / 10 / 16 四种进制互转
- 支持负数、任意位宽（不做 64 位截断），但不支持小数与浮点数
- 容量换算按 1024 进制（IEC）计算；暂无「输入 `5 MiB` 反查字节数」的解析能力，容量面板是跟随当前数值展示
- 十进制裸数字不会出现在搜索框的匹配指令里（避免和手机号、端口号、金额等混淆），需要转换时请打开界面或手动指定进制

### 权限与隐私

- **不需要 preload，不使用 Node.js 能力**：不读写本地文件、不访问剪贴板历史、不发起任何网络请求
- 所有计算都在本机插件页面内完成，无远端服务、不收集任何数据
